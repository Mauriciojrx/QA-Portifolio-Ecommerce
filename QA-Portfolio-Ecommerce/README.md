Projeto de Testes Manuais — E-commerce

Projeto desenvolvido como parte dos meus estudos em **Qualidade de Software (QA)**, com o objetivo de praticar e demonstrar conceitos de **testes manuais**, criação de casos de teste, execução, registro de evidências e documentação de bugs.

O projeto utiliza como referência um cenário de **e-commerce**, permitindo trabalhar com diferentes funcionalidades comuns em aplicações web.

## 🎯 Objetivo

Praticar o processo de testes de software desde a elaboração dos cenários e casos de teste até a execução e documentação dos resultados encontrados.

O projeto também tem como objetivo desenvolver uma visão mais crítica sobre o comportamento esperado de uma aplicação, identificando possíveis falhas e documentando-as de forma clara e organizada.

## 🔎 Funcionalidades testadas

* 🔐 Login
* 👤 Cadastro de usuário

> Novos cenários e funcionalidades poderão ser adicionados conforme a evolução do projeto.

## 🧪 Tipos de testes praticados

* Testes funcionais
* Testes positivos
* Testes negativos
* Validação de campos
* Validação de mensagens e comportamentos esperados
* Testes exploratórios
* Reexecução de cenários após identificação de problemas

### 📊 Casos_de_Teste.xlsx

Planilha utilizada para organização e documentação dos testes.

O arquivo contém abas destinadas a:

* **Login** — casos de teste relacionados à autenticação.
* **Busca** — cenários relacionados à pesquisa de produtos.
* **Cadastro** — validações relacionadas à criação de conta.
* **Recuperação** — testes relacionados à recuperação de acesso.
* **Execução** — registro dos testes executados, resultados obtidos, status e evidências.
* **Bugs** — documentação dos problemas encontrados durante os testes.
* **Listas** — informações auxiliares utilizadas na organização da planilha.

## 🐞 Registro de bugs

Os problemas identificados durante a execução dos testes são documentados com informações como:

* ID do bug
* Título
* Módulo
* Caso de teste relacionado
* Pré-condições
* Passos para reprodução
* Resultado esperado
* Resultado atual
* Severidade
* Prioridade
* Status
* Evidência

A relação entre **caso de teste, execução e bug** permite rastrear em qual cenário determinado problema foi identificado.

## 🛠️ Ferramentas utilizadas

* **Microsoft Excel** — criação e organização dos casos de teste, execução e registro de bugs.
